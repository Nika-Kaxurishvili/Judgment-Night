# 🎮 თამაში: განკითხვის ღამე

წარმოიდგინე სამყარო, სადაც კანონი მხოლოდ 364 დღით მოქმედებს...  
ერთ ღამეს კი — **ყველაფერი ნებადართულია**.

**„განკითხვის ღამე“** არის ღია სამყაროს (Open World) მოქმედებითი, გადარჩენაზე ორიენტირებული თამაში, სადაც მოთამაშეებს მოუწევთ გადარჩენა ან შურისძიება, ბრძოლის დაწყება ან დამალვა — არჩევანი შენზეა.

თამაში ვითარდება ალტერნატიულ რეალობაში, სადაც მთავრობის მიერ დაწესებული ერთღამიანი წესი ყოველწლიურად საშუალებას აძლევს მოქალაქეებს ჩაიდინონ ნებისმიერი დანაშაული — მათ შორის მკვლელობაც — ყოველგვარი სამართლებრივი შედეგის გარეშე.

---

## 🔥 მახასიათებლები

- **🌙 ღამით მოქმედება**  
  მოქმედება მიმდინარეობს მხოლოდ ერთ ღამეს — 12 საათი ტოტალური ქაოსი, დანაშაული და გადარჩენისთვის ბრძოლა.

- **🏙️ ქალაქის კვლევა**  
  იმოგზაურე სხვადასხვა უბანში, იპოვე იარაღები, რესურსები და უსაფრთხო ადგილები.

- **⚖️ მორალური არჩევანი**  
  გადაარჩინე შენი ოჯახი, დაეხმარე უდანაშაულოებს ან გამოიყენე ღამე შურისძიებისთვის.

- **🎲 დინამიკური მოვლენები**  
  შემთხვევითი შეტაკებები, თავდასხმები, დახმარების სიგნალები და მოულოდნელი სიუჟეტური ცვლილებები.
